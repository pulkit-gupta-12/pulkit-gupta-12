<summary><strong>SentinelX — Zero-Trust Cybersecurity Prototype</strong></summary>

<br />

SentinelX is an AI-assisted zero-trust cybersecurity prototype designed around continuous trust evaluation for banking environments. Instead of trusting a user only after login, the concept continuously considers user behavior, device context, location, and security events throughout a session.

| Dimension | Details |
|:---|:---|
| Stack | Web technologies, security event workflows, trust scoring, AI-assisted analysis, and prototype dashboards |
| Type | Hackathon cybersecurity prototype |
| Core Concept | Continuous verification and risk-based access decisions |
| Security Model | Zero-trust principles and adaptive trust evaluation |
| Risk Signals | Login patterns, database queries, downloads, privileged commands, location, and device context |
| AI Direction | Behavioral analysis, threat detection, explainability, and response recommendations |
| Event | Finspark’26 Hackathon, 14–16 July |
| Repository | [View Repository](https://github.com/your-github-username/sentinelx) |

### Key Contributions

- Contributed to the design of a continuous trust-evaluation workflow.
- Helped structure a dynamic Trust Score based on user, device, location, and activity signals.
- Worked on the concept of detecting suspicious behavior and potentially compromised accounts.
- Contributed to risk-based response recommendations such as MFA requirements, privilege restriction, session termination, and SOC notifications.
- Helped design a modular multi-agent architecture for future investigation and response workflows.

### Agent Architecture

The proposed LangGraph-based architecture includes specialized agents for:

- Event collection.
- Trust evaluation.
- Behavior analysis.
- Threat detection.
- Incident investigation.
- Explainability.
- Response recommendation and orchestration.

SentinelX is currently a hackathon prototype. Automated investigation, trained production models, and autonomous response workflows represent future development directions rather than claimed production capabilities.
